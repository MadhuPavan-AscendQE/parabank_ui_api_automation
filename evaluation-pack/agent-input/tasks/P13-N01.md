# P13-N01: API loan approval reconciliation

Classification: Policy-dependent automation

Prerequisite: Needs controlled loan policy with known approval inputs and expected posting semantics. Public demo approval is not deterministic.

Inputs: Dedicated deployment: loan=100.00, downPayment=20.00, source funds>=20.00; policy explicitly permits these inputs.

Acceptance: Approval, created account and ledger all match pinned policy; otherwise a specific policy/setup blocker. Implement loan adapter and cross-channel assertions.

Read the matching cases/P13-N01.json and data-contracts.json. Implement this task in the supplied standalone repository. Reuse fixtures and page/service abstractions. The requirement is currently unimplemented. Resolve missing policy or capability inputs explicitly; do not invent them.

Deliver a repository patch, mapping of acceptance criteria to assertions, actual validation commands/results and an evidence-backed blocker or diagnosis when applicable. Keep the case ID in the Playwright title and verify discovery. Do not claim that compilation or discovery is live execution.
